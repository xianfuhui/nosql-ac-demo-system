👤 User View — NoSQL Access Control Demo
NIST IR 8504 — chỉ hiển thị những gì CHÍNH user này được phép làm
🛡️ Admin Console Not logged in
🔑 Đăng nhập
Đăng nhập bằng các tài khoản demo khác nhau để thấy quyền truy cập khác nhau — mọi kết quả bên dưới đều tính lại thật theo attributes của tài khoản đang đăng nhập (không fix cứng trên UI).
🛡️ Tài khoản này có role admin. Bạn có thể vào Admin Console để quản trị policy/resource/graph/§4 demo.
🙋 Hồ sơ của tôi (subject attributes — §3.2)
Đây chính là bộ thuộc tính (role, department, clearance...) mà ABAC engine dùng để quyết định allow/deny cho mọi request của bạn.
📋 Quyền truy cập thật của tôi
Gọi GET /api/nosql-types/my-access — server chạy ABAC engine thật trên từng resource trong MongoDB với attributes của bạn. Đăng nhập tài khoản khác sẽ cho kết quả khác.
🔍 Thử mở 1 resource cụ thể
Dán Resource ID (lấy từ bảng trên) rồi bấm mở — gọi đúng endpoint GET /api/nosql-types/resources/:id mà Admin Console dùng, có ghi Audit Log thật nếu bị từ chối.
⚙️ Những gì trang User KHÔNG làm được
Để minh hoạ phân quyền thật (không chỉ ẩn UI), các nút dưới đây gọi thẳng API admin-only và cho bạn thấy response 403 thật từ server.
